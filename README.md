# Plugins for Efficiency

This repository currently contains [ClipNest](clipnest/), a local browser extension that records copied text, URLs, and image references for later reuse.

ClipNest stores data only in browser extension storage. It does not sync, upload clipboard contents, read the system clipboard in the background, or treat a right-click as an image-copy action.

See [clipnest/README.md](clipnest/README.md) for installation and verification. See [REMIND.md](REMIND.md) for maintenance and privacy constraints.
